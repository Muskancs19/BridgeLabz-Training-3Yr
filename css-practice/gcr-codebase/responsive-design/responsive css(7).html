Responsive Design

Responsive web design allows websites to adapt to different devices and screen sizes. CSS Grid, Flexbox, media queries, flexible images and relative units are commonly used to create responsive layouts.

Cheat Sheet

  • Grid — Two-dimensional layouts
  • Flexbox — One-dimensional layouts
  • Media Queries — Responsive breakpoints
  • Clamp — Flexible typography
